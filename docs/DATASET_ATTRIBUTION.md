published by user *smartgut* on Roboflow Universe:

Changes made (`coco2yolo_seg.py`): annotations converted from COCO to Ultralytics YOLO segmentation
format; the unused parent category "stool" removed, leaving classes 1–7; 294 duplicate photos removed;
the 865 unique photos re-split 75/12.5/12.5 into train/valid/test.

# Second dataset (v4 models)

The v4 models additionally train on **"Bristol-Stool-Boost"** (v1, 2025-11-22, 247 images, classification
labels only) from Roboflow Universe, project `bristol-stool-boost-thnj2-gh3ce`. The photos are crowd-sourced
(forum posts, stock photos) with self-reported Bristol types. **License: check the project page on Roboflow
Universe before publishing anything trained on it; the export README carries no license line.**

Changes made (`training/pseudo_label_boost.py`): 243 typed images (the 4 "Mixed" skipped) were resized to
640 px on the long side; segmentation masks were generated by the v3 3-group model (score ≥ 0.3) and
assigned the folder's Bristol type; 11 images with no detection were dropped. Roboflow's train/valid/test
split was kept.
